# Vocabulary reference — signs to learn

The 50 curated words for Senseless, each linked to a sign lookup. Learn **one
consistent form per word** before recording it (see [instructions.md](../instructions.md)
§5). This list is also the label set the classifier will learn.

**Sources** — the links below go to Signing Savvy search. Cross-check any word
(especially the ⚠️ ones) on:
[Lifeprint / ASLU](https://www.lifeprint.com) · [HandSpeak](https://www.handspeak.com) ·
[Spread the Sign](https://www.spreadthesign.com) *(pick American / ASL)*.

**Before you record each word**
- **Pick ONE variant and sign it identically every take** — consistency matters
  more than which variant. ⚠️ marks words with common variants to lock in.
- **Face is excluded** from the features → use the word's **manual** form.
- Keep **one- vs two-handed consistent** across takes for the same word.
- Fit the sign in **~1.5 seconds** (45-frame window); confirm `detected: yes` first.

Tick a box once you've learned that sign and are ready to collect it.

## Variant policy

For every ⚠️ word, **pick one variant and record your full set of takes (~40–50)
of only that form** — don't split takes across variants. A single word with two
visually distinct forms needs each form fully covered on its own, so sticking to
one variant keeps the class tight, the dataset balanced, and collection simplest.
(Record both forms under one label only if variant-robustness is an explicit
goal — and then give *each* form its own full ~40–50 takes, not a 25/25 split.)

**Decisions locked in**
- **GOODBYE** → the flat-hand **wave, side to side**.

## Look-alike pairs — sign these distinctly

The classifier can confuse signs that share a location/handshape. Exaggerate the
difference and stay consistent:

- **KNOW / THINK** — both at the forehead; keep the handshape difference clear.
- **GOOD / THANK-YOU** — both start at the chin; make the movement distinct.
- **YES / NO** — small fist "nod" vs. finger snap; don't rush them.
- **HOT / COLD** — keep the handshapes and motions clearly different.
- **ME / YOU** — both are points; direct them unambiguously (self vs. camera).
